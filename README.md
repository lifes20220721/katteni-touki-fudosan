# かってに登記申請 — 不動産登記版

公開URL：https://lifes20220721.github.io/katteni-touki-fudosan/

相続登記の準備を、ご自身のペースで進めるブラウザ内完結の試作版です。司法書士PASS・行政書士PASSとは別アプリです。シリーズ名を「かってに登記申請」、版名を「不動産登記版」として表示します。

## アプリ説明文

**相続登記の準備を、一歩ずつ。**

2024年4月1日から、相続による不動産登記が義務化されました。不動産を相続で取得したことを知った日から、原則3年以内に申請する必要があります。施行前の相続も対象となり、2024年4月1日より前に取得を知っていた未登記の不動産は、原則2027年3月31日までの対応が必要です。

「かってに登記申請 不動産登記版」は、被相続人・相続人・不動産の情報を整理し、必要資料と取得先、申請期限の目安、参考の法定相続分、登記申請書・遺産分割協議書の下書きを確認できる、ご自身で手続を進めるための準備アプリです。

入力した個人情報はブラウザ内で処理し、サーバーへ送信しません。必要なときだけ端末に保存できます。

※自動で登記申請を行うアプリではありません。個別の法律相談や代理申請は提供しません。現在は試作版・専門家レビュー未実施のため、生成した下書きをそのまま提出することはできません。期限や必要資料は事情により異なるため、管轄法務局等への確認が必要です。

短い紹介文：**相続登記の義務化に備えて、家族・不動産の情報整理から必要資料の確認、申請書類の下書きまで。ご自身で進める登記の準備を支援します。**

## 起動・検証

Node.js 24以上。依存ライブラリのインストールは不要です。

```sh
npm test
npm run check
python3 -m http.server 4173
```

http://localhost:4173/ を開きます。ESモジュールを使うためHTMLの直接ダブルクリックでは動きません。HTTPSまたはlocalhostでService Workerが利用できます。Androidのインストール表示はブラウザの要件・状態によります。オフライン対応コードと192/512pxアイコンを用意していますが、実機・実ブラウザのインストール動作は未確認です。

## 現在の機能

- スマホ向けフォーム、人数照合、証明資料の確認ステップ
- 単純な配偶者＋子、子のみの参考持分（戸籍確認後のみ）
- 法定相続・全不動産を一名が取得する遺産分割の固定版下書き
- 必要資料のチェックリスト・取得先と手順・原本還付と管轄の案内
- 期限の一般案内、2026年10月5日からの国籍等・証明資料の確認
- 対象内の単独所有物件の評価額×0.4%の単純参考額。税額欄へ転記しない
- 変更時の確認解除と下書き消去、JSON保存・復元（復元時も確認解除）
- 印刷/PDF保存。入力の自動保存・送信なし。オフライン用キャッシュは公開静的資産のみ

## 個人情報とセキュリティ

入力データはページのメモリ内だけに保持します。再読込・終了で失われます。利用者が保存操作をした場合のみ、個人情報を含むJSON/PDFが端末に残ります。GitHubにアップロードしないでください。添付の認証JSONを本アプリに使用していません。秘密鍵・認証情報・実在の個人情報はリポジトリに含めません。

ユーザー文字列は `textContent` またはフォームの `value` で扱い、HTMLとして実行しません。JSONはサイズ・型・列挙値・ID重複・未知キー等を検証します。外部スクリプト・AI・広告・解析・API送信・クラウド保存はありません。外部の公式リンクを利用者が開く通信と、静的アプリ資産の配信・更新は発生します。CSPでフォーム送信・オブジェクト・外部スクリプトを制限します。サーバーAPIやCookie認証を持たないため、変更リクエストへのCSRF機構は現在不要です。APIを追加する場合は改めて設計が必要です。

GitHub PagesはHTTPレスポンスヘッダーの任意設定ができません。meta CSPを使用していますが、`frame-ancestors`等のヘッダー専用設定は別の配信層を設計する必要があります。

## 未対応・要監修

遺言、相続放棄、代襲・数次相続、親や兄弟姉妹の相続、配偶者のみ、未成年、外国籍・国外関係、被相続人の共有持分、区分建物、時系列の親族グラフ、不動産ごとの異なる取得者・持分、2013年9月5日より前の相続、免税判定・正確な税計算、電子申請、OCRは未対応です。対象外では下書き生成を停止します。

公式の最新様式一覧・検索用情報の案内本文は2026年11月18日に確認しました。個別のWord/PDF全項目・印刷配置の照合と専門家レビューは未完了です。申請人表示・添付情報・国籍証明情報・税額欄を含む生成物は提出不可です。提出用様式が完成したと表示しません。

有償化、書類作成代行、個別相談・代理申請は、司法書士法等を踏まえ専門家と提供形態を確認してから設計します。2019年の特定の商業登記事案の規制解釈を、相続登記一般への許可とみなしません。

## v0.2：所在地から管轄を自動入力

基本情報の「登記対象不動産の所在地（1件目）」に都道府県・市区町村（政令市は区）を入力すると、不動産登記の管轄法務局・支局・出張所を候補として入力します。被相続人の最後の住所ではなく、不動産の所在地を使います。STEP 03の1件目所在地と相互に連動します。

全国47都道府県・50局の公式管轄表の不動産登記欄を2026-11-18に取得し、対応表をアプリに同梱しています。住所を検索サービスに送る処理はありません。出典と確認日は `data/jurisdiction-sources.json`、元の区域の記載と判定用の住所接頭辞は `data/jurisdictions.js` にあります。商業・法人登記の管轄列は使用しません。

町域で管轄が分かれるケース（例：成田市・松山市等）、住所が未完了または一致しないケースでは自動入力を止めます。表示する公式管轄表で確認し、「公式表で確認して管轄を手入力する」で入力できます。所在地変更時は手入力した申請先も消去し、古い申請先を残しません。複数不動産が異なる管轄の場合は申請先ごとに案件を分けるよう案内し、下書き生成を止めます。

既存のv1保存JSONも読み込めます。旧ファイルでは所在地を空欄として補完し、既存の申請先を手入力扱いで保持します。所在地の再入力と資料の再確認が必要です。PWAキャッシュを更新していますが、入力中の画面を強制更新しません。古い画面が残る場合は、入力をJSONに保存してからアプリを閉じて開き直してください。

テスト実行環境はNode.js 24以上です。データ更新スクリプト `scripts/build-jurisdictions.py` は公開公式ページの取得結果JSON（url/title/text）を入力とし、個人情報を扱いません。全住所の完全な名寄せや管轄確定を保証するものではなく、例外のある表は保守的に手入力確認へ回します。提出前に最新の管轄表を確認してください。

## v0.2.1：評価額・不動産の表示の調べ方

STEP 03の各不動産に、折りたたみ式の「評価額の調べ方・評価証明書の入手方法」「不動産の表示の調べ方・登記事項証明書の入手方法」を追加しました。課税明細書の価格（評価額）と課税標準額の違い、所在地の自治体（東京23区は都税事務所）での評価証明書等の請求、地番・家屋番号の確認、登記事項証明書の窓口・郵送・オンライン請求を案内します。

必要資料一覧の「登記事項証明書」「当該年度の固定資産評価額が分かる資料」からも取得案内に進めます。自治体の探し方はJ-LISの自治体公式サイト一覧へ、東京23区の例は東京都主税局へリンクします。東京23区の手続きを全国共通の手続きとして扱いません。手数料は固定表示せず、請求先の最新案内へ誘導します。リンクに入力内容を含めず、利用者が開いたときだけ外部サイトへ移動します。
