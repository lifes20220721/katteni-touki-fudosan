# タスク01：土台と安全化（P0-1）

作業日：2026-11-21。アプリ版：0.2.3。専門家レビュー未実施。

## 対象と変更

v0.1から継続開発されているリポジトリのv0.2.2を基点に、既存機能を保持して責務を分離した。今回、法的な判定内容・ルール版（2026-11-18.2）・下書きテンプレート版を変更していない。P0-2の全面的な様式再設計、P1の親族グラフには進んでいない。

| モジュール | 責務 |
|---|---|
| `src/model.js` | 入力スキーマ、JSON検証、架空の空データ、確認解除 |
| `src/heirs.js` | 相続人入力の人数・続柄・重複の検査 |
| `src/state.js` | 入力操作の許可リスト、検証後の一括更新、JSON往復、プレビューの版管理 |
| `src/rules.js` | 法定ルール、参考持分、期限・税額の参考案内と停止判定 |
| `src/documents.js` | 固定版の申請書・協議書下書き、資料ガイド |
| `src/view.js` | DOM描画と入力イベント。個人情報はvalue/textContentで表示 |
| `src/app.js` | 各モジュールの接続、利用者操作による保存・読込・印刷 |

すべての入力更新をstate経由に統一した。内容変更時は確認とプレビューを解除し、描画側でも古い本文を消去する。確認チェック・資料入手チェックの変更でも既存プレビューを消去する。JSON復元時も確認とプレビューを解除する。不正な操作・JSONは現在の入力を置き換えない。外部に返す状態・下書きはコピーで、参照経由の変更を防ぐ。

相続人の人数と戸籍で確認した配偶者・子の人数の不一致、重複、対象外の続柄を検出する。相続人の削除後も人数不一致なら生成を停止する。取得者を削除すると選択を解除する。相続人追加・削除が不動産管轄の手入力を消去していた不具合を修正した。

入力はメモリ内のみ。通信・クラウド保存・自動永続保存を追加していない。公開静的資産のみPWAキャッシュに含める。テストデータは架空のみ。外部リンクは固定URLで、入力情報を含めない。

## 指定ケースと検証

既存 `tests/core.test.js` と `tests/jurisdiction.test.js` の52件は内容・期待値とも変更なし。`tests/state.test.js` に25件追加し、合計77件成功（失敗・スキップ0）。`npm run check` はJavaScript 9ファイルの構文検査に成功。

| 指定ケース | 検証内容（既存coreテスト） |
|---|---|
| 配偶者1・子2 | 配偶者1/2、子各1/4 |
| 配偶者0・子2 | 子各1/2 |
| 親と子 | 自動確定・文書生成停止 |
| 配偶者のみ | 他順位不確認で停止（現在は配偶者のみ全般が対象外） |
| 遺産分割一名取得 | 選択者名義の申請書、全相続人の協議書下書き |
| 施行前の未登記 | 2027年3月31日の経過措置案内 |
| 2026年10月5日以降 | 国籍等・証明情報・照合不足で停止 |
| 100万円以下の土地 | 確定税額を示さず警告・単純概算停止 |
| 遺言等の複雑事案 | 遺言・放棄・代襲・数次・未成年・国外・共有は生成停止 |
| JSON往復 | 入力復元、確認解除、不正JSON拒否 |
| HTML文字列 | 文字列保持、安全な出力API、実ブラウザで非実行 |

追加テストは氏名・住所・人数・相続人追加削除・承継方法・不動産情報・複雑事案フラグ等の変更時のプレビュー無効化、再確認後の更新文書、手入力管轄の保持、取得者削除、不正更新の原子性、外部参照からの状態改変防止を検証する。

localhostのデスクトップChromeで、架空の子1名を入力し下書き生成を確認。氏名のimg/onerror、住所のscriptが文字列として表示され、出力先の該当要素数0・ダイアログなしを確認。氏名変更で下書き領域非表示・本文空・戸籍確認解除を確認。相続人追加削除後も手入力管轄が維持された。コンソールエラーなし。

実ブラウザのJSON保存・復元往復はダウンロード待機タイムアウトで未確認。単体テストのJSON往復成功と区別する。Android実機、PWAインストール・オフライン更新、印刷改ページは未確認。
